## Featured project

### Wind Turbine Site Planner

An ArcGIS Pro geoprocessing tool for preparing and validating wind-turbine planning data. It automates important planning calculations and spatial attributes according to turbine geometry, federal-state rules and the selected planning context.

**Key capabilities**

- Automated German **Baulastkreis** calculation
- Turbine total-height and above-ground-height calculations
- Rotor, foundation and eccentricity processing
- Parcel and administrative-area attribution
- Input validation and structured geoprocessing output
- Reusable turbine and calculation reference tables

**Technology:** Python · ArcPy · ArcGIS Pro · Geoprocessing

> The source code and project data are maintained in a private repository.
